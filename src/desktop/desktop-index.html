SpectraTact Help

Getting Started

  1. Click Start Apps to launch all applications
  2. Use window management controls to arrange applications
  3. Switch between different app profiles using Load Apps panel
  4. Use keyboard shortcuts for quick actions

Window Management

  • Arrange: Organize windows in a grid layout
  • Minimize: Minimize all application windows
  • Refresh: Update the list of active applications

Keyboard Shortcuts

  • Ctrl+S: Start all applications
  • Ctrl+R: Refresh app
  • Ctrl+A: Select all applications
  • Ctrl+D: Clear application selection
  • Ctrl+G: Arrange windows in grid layout

Tips

  • Use the theme toggle to switch between light and dark modes
  • The status indicator shows connection health
  • Right-click the menu button for additional options
